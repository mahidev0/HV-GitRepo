# Question 4: Handling Errors (Stash, Reset, Revert)

## Objective
Learn how to manage mistakes and unfinished work using Git.

---

## Tasks Performed

- Modified app.py without commit
- Stashed changes including untracked files
- Checked stash list
- Applied stashed changes
- Created commits
- Undid commits using reset
- Reverted commits safely
- Verified commit history

---

## Commands Used

```bash
git stash -u

git stash list

git stash apply

git reset --soft HEAD~1

git reset --hard HEAD~1

git revert HEAD

git log

git log --oneline
```

---

## Outcome

Successfully learned stash, reset, and revert operations in Git.
